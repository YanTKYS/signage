# iSignage

`isignage.html` 1ファイルだけで動作する、ローカル PC 用のデジタルサイネージ作成・表示ツールです。PowerPoint に近い感覚で、テキスト、画像、動画、フォルダ再生メディア、時計、図形を 1920×1080（16:9）のキャンバスへ配置し、全画面で再生できます。

Web サーバー、npm、外部ライブラリ、CDN は不要で、外部通信も行いません。

## 動作環境

- Microsoft Edge 最新版
- Google Chrome 最新版

メディアフォルダの選択に File System Access API を使用するため、Firefox や Safari ではフォルダ再生を利用できません。

## 起動方法

1. `isignage.html` をローカル PC に置きます。
2. Edge または Chrome で直接開きます。
3. 上部の「? ヘルプ」から、基本操作、メディアフォルダ、シーン、保存、ショートカットを同一 HTML 内で確認できます。初回起動時は簡単な案内を表示し、「次回から表示しない」で抑止できます。

## オブジェクトの編集

- 上部ツールバーの「テキスト」「画像」「動画」「メディア」「図形」「時計」から追加します。
- クリックで選択、ドラッグで移動、選択枠の 8 ハンドルでサイズ変更します。画像と動画は四隅ハンドルで縦横比を維持し、`Shift` で維持/解除を一時的に反転できます。
- キャンバスの空白をドラッグすると範囲選択、`Ctrl` を押しながらのドラッグまたはクリックで選択の追加・解除ができます。
- 右側のプロパティ欄から位置、サイズ、回転、透明度、色、書式、再生設定などを変更できます。不正な数値は安全な範囲へ補正し、空欄のまま確定した場合は元の値へ戻します。
- 整列、等間隔配置、中央配置、重なり順の変更、グリッド、吸着、中央線ガイドに対応しています。
- ロックしたオブジェクトは選択とプロパティ編集はできますが、移動、サイズ変更、整列、削除の対象になりません。
- 値が変わらない操作（選択のみのクリック、境界での移動、整列済み対象の再整列など）は Undo 履歴と未保存状態に記録しません。

## ショートカット

| 操作 | キー |
| --- | --- |
| 削除 | `Delete` |
| コピー / 貼り付け / 複製 | `Ctrl+C` / `Ctrl+V` / `Ctrl+D` |
| 元に戻す / やり直す | `Ctrl+Z` / `Ctrl+Y`、`Ctrl+Shift+Z` |
| 全選択 | `Ctrl+A` |
| 1px 移動 / 10px 移動 | 矢印キー / `Shift+矢印キー` |
| 選択解除、表示モード終了 | `Esc` |

macOS では `Ctrl` の代わりに `Command` も利用できます。貼り付けと複製はコピーを 30px ずらして配置し、キャンバス外へは出しません。

## シーン

左ペインの「シーン設定」から、シーン名、背景色、表示秒数（1 秒以上）を編集できます。シーンの追加、複製、削除、並べ替えに対応し、「シーン切替」で「切り替えない」「指定秒数ごと」「ランダム」を選べます。

左シーン欄は「‹ シーン欄を閉じる」で折りたたみ、キャンバス左端の「› シーン欄を開く」で再表示できます。開閉状態は保存され、次回起動時に復元されます。

## メディアフォルダ再生

「メディア」オブジェクトを追加し、プロパティ欄の「フォルダを選択」でフォルダを指定します。フォルダ内の画像・動画をファイル名順またはランダムで再生し、サブフォルダを含める設定にも対応します。画像は指定秒数で、動画は再生終了で次へ進みます。

「自動更新」を有効にすると、表示モード中にプレイヤー単位でフォルダを再走査します。更新間隔は最低 1 分です。更新に失敗した場合は最後に取得できた一覧を維持して次回再試行し、読み込めないファイルやサブフォルダはその項目だけを飛ばします。読み込みに失敗したファイルは、一覧の更新に成功するまで再生候補から除外します。

編集モードでは「手動更新」でフォルダ名、画像数、動画数、合計件数、最終更新時刻、読込状態を更新できます。これらの情報欄と単一画像・動画のファイル名は読取専用です。

## 表示モード

上部の「▶ 表示開始」で編集 UI を隠し、全画面表示を要求します。キャンバスは画面に合わせて等比率表示し、余白は黒背景になります。全画面表示に失敗した場合も通常表示で継続します。

表示モード中は `Esc` 以外の編集ショートカットを受け付けません。`Esc`、またはブラウザ側の全画面解除操作で編集モードへ戻り、シーン自動切替で位置が進んでいた場合も表示開始前のシーンを選び直します。

動画とメディアプレイヤーの既定値はミュートです。ミュートを解除した動画の自動再生がブラウザに拒否された場合は、その表示セッションに限りミュートで再生を続けます（設定値は変更しません）。

## 保存とバックアップ

- 編集内容は IndexedDB へ自動保存されます。「保存」で手動保存もできます。
- 「JSON出力」でバックアップを書き出し、「JSON読込」で復元できます。
- JSON 出力には `app: "iSignage"` と `format: "isignage-backup"` の識別情報を含めます。識別情報を持たない旧バックアップも、`version` と `scenes` の構造から判定して読み込みます。
- 読込時は構造を検証し、iSignage 形式でない JSON は拒否します。不正な値は無視または補正し、識別子の重複は一意な値へ補正します。読込に失敗した場合、編集内容、Undo/Redo 履歴、保存内容は変更しません。
- JSON にはフォルダのアクセス権限、メディアファイルの実体、単一画像・動画の永続的な参照は含まれません。別端末へ移行した場合は、読込後にメディアを再指定してください。
- 「新規」「初期化」は現在の編集内容と保存済みのフォルダ参照をすべて破棄します。

## メディアフォルダのアクセス権限

フォルダのアクセス権限は File System Access API に依存します。ブラウザ再起動、端末変更、権限取り消しなどにより、フォルダの再選択が必要になることがあります。

ディレクトリハンドルは IndexedDB に保存します。コピー、貼り付け、シーン複製したメディアプレイヤーは同じフォルダ参照を共有します。Undo／Redo でフォルダ参照を復元できるよう、オブジェクト削除やフォルダ再選択では使用しなくなった参照を直ちには削除せず、「新規」「初期化」でまとめて破棄します。

## 既知の制限

- 単一画像・単一動画はブラウザが保持するファイル参照に依存するため、元ファイルの移動や削除で表示できなくなります。長期運用ではメディアフォルダ再生を推奨します。
- `file://` での実行を前提とするため、ブラウザ設定や企業ポリシーにより File System Access API が制限され、フォルダ選択を利用できない場合があります。
- 回転したオブジェクトの当たり判定とサイズ変更は回転前の矩形を基準にするため、大きく回転した状態では操作位置と見た目がずれます。

## GitHub Pages への公開

`main` ブランチの `isignage.html` を更新すると、GitHub Actions が同ファイルを `index.html` として GitHub Pages へ公開します。Actions の手動実行にも対応しています。リポジトリで Pages が未有効の場合は、`PAGES_TOKEN` シークレットへ Pages を有効化できる Personal Access Token を設定してください。
